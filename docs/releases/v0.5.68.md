# 0.5.68 — 动作镜像、界面隐藏与多人播放修复

相较上一发布版 **0.5.58**：

- **动作与镜头镜像**：可分别开启左右镜像，支持 VMD 和 Blender 导出文件；多人可逐位队员设置，保留原队伍站位。
- **配乐播放时静音游戏 BGM**：在“镜头与音乐”中开启，保留游戏音效和语音；暂停、停止或配乐结束后恢复，不修改游戏音量设置。
- **隐藏游戏 UI**：主面板开关或 **Ctrl+H** 隐藏／恢复游戏界面，保留 Poser 面板；**Esc** 也可恢复。
- **角色隐藏修复**：修复 VMD 模型显示开关未能实际隐藏角色的问题，兼容单人、多人及分层录制，停止后恢复原状态。
- **多人播放准备修复**：处理女管理员等角色衣物骨骼缩放异常导致的准备失败；等待物理就绪或准备失败时，在播放器直接提示对应队员。

## 安装与更新

1. 完全退出游戏，将上方 **win64.zip** 完整解压到游戏目录之外。
2. 运行 **安全安装.bat → 安装本地包**，选择包含 `Endfield.exe` 的目录；也可通过原安装向导选择 **在线安装 / 更新**。
3. 配置、姿态和自定义校准保留，旧文件自动备份。启动后按 **L** 打开面板。

Blender 联动仍为 **0.3.2**，已安装该版本无需重复更新。附件只提供编译好的标准安装包；GitHub 自动列出的 **Source code** 不能直接安装。
