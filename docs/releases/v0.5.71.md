# 0.5.71 — 扩展骨适配与映射保存改进

相较上一发布版 **0.5.68**：

- **动作扩展骨适配**：新增通用握拳、张指、手臂 IK 和视线目标控制，支持插入多段父级及手动绑定轨道，可调整轴向、比例和控制部位。
- **导入问题提示**：单人和小队各动作分别检查，用橙色标出需要处理的轨道；可查看原因、首个问题关键帧，筛选或明确忽略轨道，仅归零的轨道单独收起。
- **映射保存改进**：选择多条映射后，点击“应用并保存适配预设”即可一起生效，切换编辑轨道不丢失选择。增加同窗载入入口，重启后恢复最近成功保存或载入的预设；依赖 PMX 的预设需先手动选择对应骨架。
- **映射状态更清楚**：已应用的设置保留显示为“已手动映射”，尚未应用显示“待应用”；绑定仍有问题时显示“已手动映射，需检查”及原因，被替换的原轨道不再误报未映射。

入口：导入 VMD 后点击文件名下方的 **查看并处理…** 或 **检查动作扩展骨…**。骨架适配由单人与小队共用，修改前请停止播放；播放或暂停时可保存已生效的设置。特殊动作仍需核对轴向、比例和父级，通用控制不能精确还原所有作者的专用骨架。

## 安装与更新

1. 完全退出游戏，将上方 **win64.zip** 完整解压到游戏目录之外。
2. 运行 **安全安装.bat → 安装本地包**，选择包含 `Endfield.exe` 的目录；也可通过原安装向导选择 **在线安装 / 更新**。
3. 配置、姿态和自定义校准保留，旧文件自动备份。启动后按 **L** 打开面板。

Blender 联动仍为 **0.3.2**，已安装该版本无需重复更新。附件只提供编译好的标准安装包；GitHub 自动列出的 **Source code** 不能直接安装。
